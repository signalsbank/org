# KB-ONB-02 — Glosario

Términos de uso frecuente en la wiki y en los proyectos.

| Término         | Significado                                                                           |
| :-------------- | :------------------------------------------------------------------------------------ |
| **ADR**         | Registro de una decisión de arquitectura: contexto, alternativas y consecuencias.     |
| **API**         | Interfaz mediante la cual dos sistemas intercambian datos.                            |
| **CCB**         | Comité que aprueba o rechaza cambios de línea base.                                   |
| **DoD**         | Definition of Done: criterios que debe cumplir una tarea para considerarse terminada. |
| **PR**          | Pull request: propuesta de cambio que se revisa antes de integrarse.                  |
| **Post-mortem** | Análisis posterior a un incidente, sin culpables.                                     |
| **RFC**         | Propuesta formal de cambio que requiere evaluación de impacto.                        |
| **Runbook**     | Procedimiento paso a paso para operar o recuperar un sistema.                         |
| **SCM**         | Gestión de la configuración: control de versiones y de la línea base.                 |

## Cómo se mantiene

- Cada término nuevo se agrega en el mismo PR que lo introduce.
- El glosario no reemplaza la documentación: solo define.
- Si un término tiene sigla, se define la primera vez en cada documento y se enlaza acá.
