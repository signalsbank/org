# 07 — Activos de IA

Prompts, agentes y skills versionados, con dueño y ámbito de uso definidos.

## Reglas

1. Todo activo tiene dueño, versión y ámbito de uso.
2. Un activo de IA **no es la estrategia**: es una interfaz de consulta sobre la misma base de
   conocimiento.
3. Las respuestas deben citar el documento fuente y respetar los permisos del usuario.
4. No se envían datos confidenciales ni personales a servicios externos sin autorización.
