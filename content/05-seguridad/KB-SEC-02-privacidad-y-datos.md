# KB-SEC-02 — Privacidad y datos

**Objetivo:** tratar los datos personales con el mismo criterio en todos los proyectos.

## Reglas

- **Minimización:** se recopila solo lo necesario para la finalidad declarada.
- **Datos de ejemplo:** siempre sintéticos o anonimizados. Nunca se copian registros reales a la
  wiki, a los tests ni a los entornos de desarrollo.
- **Acceso:** cada persona accede solo a los datos que necesita para su rol.
- **Conservación:** los datos se eliminan cuando termina la finalidad; el plazo se documenta en el
  proyecto.
- **Trazabilidad:** quién accedió, cuándo y para qué, cuando el proyecto lo requiera.

## Antes de publicar un documento

- [ ] No hay nombres, documentos, teléfonos ni direcciones reales.
- [ ] No hay capturas con datos de personas.
- [ ] No hay credenciales ni rutas internas sensibles.
- [ ] El nivel de clasificación está indicado.

## Marco de referencia

Ley 25.326 de Protección de los Datos Personales (Argentina). Cada proyecto verifica si le aplica
normativa adicional.
