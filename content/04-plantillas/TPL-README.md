# TPL-README — Plantilla de README de proyecto

> Copiar al repositorio del proyecto como `README.md` y completar cada sección.

## Secciones

```md
# Nombre del proyecto

Qué es, en dos o tres frases, y para quién.

## Requisitos

- Versión de lenguaje y gestor de paquetes.
- Servicios externos necesarios (base de datos, almacenamiento).

## Instalación

Pasos mínimos para levantar el entorno local. Enlazar `SETUP.md` para el detalle.

## Uso

Comandos principales y un ejemplo corto.

## Estructura

Árbol de carpetas relevantes, sin listar cada archivo.

## Documentación

- Índice de `docs/`.
- Decisiones de arquitectura (`ADR`).
- Cómo contribuir y cómo se revisa un PR.
```

## Regla

El `README` no repite la documentación técnica: la presenta y la enlaza.
